# YVC Cosmetics

Навчальний вебпроєкт із дисципліни «Веб-орієнтована розробка програмного забезпечення» (КПІ ім. Ігоря Сікорського, ННІ ПСА).

Сайт косметологічної клініки YVC Cosmetics з онлайн-записом і особистим кабінетом клієнта.
Концепцію, брендбук і вимоги описано в лабораторній роботі №1.

| Папка | Лабораторна робота | Що додано |
|-------|--------------------|-----------|
| [`lab2/`](lab2/) | №2 — Структура вебпроєкту | Семантичні HTML-сторінки, форми, зображення |
| [`lab3/`](lab3/) | №3 — CSS | Стилі за брендбуком, адаптивність, бургер-меню, валідація HTML5 |
| [`lab4/`](lab4/) | №4 — JavaScript | DOM, події, валідація форм на JS, LocalStorage, кабінет зі скасуванням запису |

Кожна наступна лабораторна — копія попередньої з новими змінами.

**Виконавці:** Ходисько Є.А., Щербаков О.Г. (група КІ-41)
