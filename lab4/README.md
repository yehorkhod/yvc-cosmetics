# YVC Cosmetics — Лабораторна робота №4

Інтерактивність сайту косметологічної клініки YVC Cosmetics на JavaScript: робота з DOM, подіями, валідація форм і LocalStorage. Основа — сайт із ЛР3 (HTML з ЛР2 + CSS).

**Виконавці:** Ходисько Є.А., Щербаков О.Г. (група КІ-41)

## Сторінки

| Файл | Сторінка | Вміст |
|------|----------|-------|
| `index.html` | Головна | Головний екран, популярні процедури, переваги, відгуки |
| `about.html` | Про нас | Історія, принципи роботи, обладнання, ліцензія |
| `services.html` | Послуги та ціни | Прайс у таблицях за категоріями |
| `doctors.html` | Лікарі | Картки лікарів зі стажем і спеціалізацією |
| `booking.html` | Онлайн-запис | Форма запису: послуга, лікар, дата, час, контакти |
| `contacts.html` | Контакти | Адреса, графік, карта, форма зворотного зв'язку |
| `login.html` | Вхід | Форми входу та реєстрації |
| `account.html` | Особистий кабінет | Майбутні записи (скасування, перенесення), історія візитів |

## Технічні рішення

- Семантичні елементи `header`, `nav`, `main`, `footer`, `section`, `article`, `address`, `blockquote`, `time`.
- Спільне меню навігації на всіх сторінках, поточна сторінка позначена `aria-current="page"`.
- Усі зображення мають `alt`; фото подано у форматі WebP з JPG-запасним варіантом через `<picture>` і завантажуються ліниво (`loading="lazy"`).
- Форми: онлайн-запис, зворотний зв'язок, вхід і реєстрація; кожне поле має `<label>`.
- Усі сторінки перевірено W3C Validator (0 помилок).

## CSS (ЛР3)

- **Організація стилів:** `style.css` об'єднує `base.css`, `layout.css` і `components.css` директивою `@import`; кольори, шрифт і відступи винесено в CSS-змінні (`:root`).
- **Брендбук:** королівський синій `#395AB0`, темний синій `#364870`, пісочне золото `#E1CA8D`, статусні червоний `#C53030` і зелений `#1F7A4D`; шрифт Roboto (Google Fonts); прямокутні кнопки з тонкою рамкою.
- **Адаптивність (mobile-first):** медіазапити `@media (min-width: 600px)` для планшета та `@media (min-width: 900px)` для ПК; гнучкі розміри заголовків через `clamp()`.
- **Flexbox:** шапка, меню, кнопки, картки лікарів, рядки форм.
- **CSS Grid:** сітка популярних процедур (1 → 2 → 4 колонки), двоколонкові блоки «текст + фото», картки лікарів, підвал.
- **Бургер-меню без JavaScript:** прихований `checkbox` + `label`, меню відкривається селектором `.nav-toggle:checked ~ .main-nav`.
- **Валідація форм:** HTML5-атрибути `required`, `minlength`, `pattern`, `type="email"`; помилки підсвічуються через `:user-invalid` і `:has()` (лише після взаємодії з полем), під полем показується текст помилки.
- **Кросбраузерність** (Chrome, Firefox, Safari, Edge): префікси `-webkit-` для `backdrop-filter`, `appearance`, `text-size-adjust`; власна стрілка для `<select>`, однакова висота полів; фон головного екрана у форматі WebP.
- **Доступність:** посилання «Перейти до основного вмісту», видимий фокус `:focus-visible`, контраст тексту ≥ 4,5:1, повага до `prefers-reduced-motion`.

## JavaScript (ЛР4)

Файл `js/main.js` підключено в кінці `<body>` на всіх сторінках: `<script src="./js/main.js"></script>`.

| Завдання | Реалізація |
|----------|-----------|
| **DOM: зміна стилю елементів** | `querySelectorAll('.price-row--promo')` — акційні рядки прайсу отримують золотий фон і напівжирний шрифт |
| **DOM: новий елемент** | `createElement('p')` + `append()` у кінець `<main>` на сторінці послуг — термін дії акцій (останній день поточного місяця) |
| **Поточна дата у футері** | `Intl.DateTimeFormat('uk-UA')` → `<time id="current-date">` |
| **Акордеон «Показати більше»** | Кнопка перемикає атрибут `hidden` блоку та `aria-expanded` |
| **Зміна теми** | Кнопка «Темна тема» перемикає клас `dark-theme` на `<html>`; вибір зберігається в `localStorage` |
| **Підсвітка меню** | Події `mouseenter`/`mouseleave` (і `focus`/`blur`) додають/знімають клас `.is-hovered` — без CSS `:hover` |
| **Клавіші ↑ / ↓** | `keydown` змінює розмір шрифту сторінки від 12 до 24 px (крок 2 px), розмір зберігається; у полях форм стрілки працюють як звичайно |
| **Обробка submit** | `event.preventDefault()`, дані зчитуються через `FormData` і виводяться в консоль |
| **Валідація** | Контакти: ім'я ≥ 3 символи, email з `@` і доменом, повідомлення ≥ 10 символів. Запис: послуга, дата не в минулому, час, телефон `+380XXXXXXXXX`, згода. Вхід/реєстрація: email, пароль ≥ 8 символів. Поле з помилкою підсвічується червоним, текст помилки — під полем; після успіху форма очищується й показується «Форма успішно надіслана!» |
| **LocalStorage (бонус)** | Тема, розмір шрифту, ім'я користувача, обліковий запис і список записів на прийом |

### Особистий кабінет

- Вхід/реєстрація зберігають користувача в `localStorage` (демо без сервера); без входу `account.html` перенаправляє на `login.html`; у шапці «Увійти» змінюється на «Кабінет».
- Записи з форми онлайн-запису одразу з'являються в кабінеті; при першому вході додаються демо-записи з датами відносно поточного часу.
- **Скасування** — з підтвердженням `confirm()`, лише якщо до візиту більше 24 годин; запис переходить в історію зі статусом «Скасоване».
- **Перенесення** — відкриває форму запису (`booking.html?reschedule=<id>`) із уже вибраними послугою й лікарем.
- Якщо до візиту менше 24 годин, кнопки неактивні з підказкою зателефонувати в клініку.
- Кнопка «Записатись до лікаря» на сторінці лікарів відкриває форму з уже вибраним лікарем (`booking.html?doctor=...`).
