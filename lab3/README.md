# YVC Cosmetics — Лабораторна робота №2

Структура вебсайту косметологічної клініки YVC Cosmetics: семантична HTML-розмітка сторінок, визначених у ЛР1.

**Виконавці:** Ходисько Є.А., Щербаков О.Г. (група КІ-41)

## Сторінки

| Файл | Сторінка | Вміст |
|------|----------|-------|
| `index.html` | Головна | Головний екран, популярні процедури, переваги, відгуки |
| `about.html` | Про нас | Історія, принципи роботи, обладнання, ліцензія |
| `services.html` | Послуги та ціни | Прайс у таблицях за категоріями |
| `doctors.html` | Лікарі | Картки лікарів зі стажем і спеціалізацією |
| `booking.html` | Онлайн-запис | Форма запису: послуга, лікар, дата, час, контакти |
| `contacts.html` | Контакти | Адреса, графік, карта, форма зворотного зв'язку |
| `login.html` | Вхід | Форми входу та реєстрації |
| `account.html` | Особистий кабінет | Майбутні записи (скасування, перенесення), історія візитів |

## Структура

## Технічні рішення

- Семантичні елементи `header`, `nav`, `main`, `footer`, `section`, `article`, `address`, `blockquote`, `time`.
- Спільне меню навігації на всіх сторінках, поточна сторінка позначена `aria-current="page"`.
- Усі зображення мають `alt`; фото подано у форматі WebP з JPG-запасним варіантом через `<picture>` і завантажуються ліниво (`loading="lazy"`).
- Форми: онлайн-запис, зворотний зв'язок, вхід і реєстрація; кожне поле має `<label>`.
- Усі сторінки перевірено W3C Validator (0 помилок).
