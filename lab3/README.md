# YVC Cosmetics — Лабораторна робота №3

Оформлення сайту косметологічної клініки YVC Cosmetics за допомогою CSS відповідно до брендбуку з ЛР1. Основа — сторінки з ЛР2.

**Виконавці:** Ходисько Є.А., Щербаков О.Г. (група КІ-41)

## Сторінки

| Файл | Сторінка | Вміст |
|------|----------|-------|
| `index.html` | Головна | Головний екран, популярні процедури, переваги, відгуки |
| `about.html` | Про нас | Історія, принципи роботи, обладнання, ліцензія |

| `booking.html` | Онлайн-запис | Форма запису: послуга, лікар, дата, час, контакти |

| `account.html` | Особистий кабінет | Майбутні записи (скасування, перенесення), історія візитів |

## Технічні рішення

- Семантичні елементи `header`, `nav`, `main`, `footer`, `section`, `article`, `address`, `blockquote`, `time`.
- Спільне меню навігації на всіх сторінках, поточна сторінка позначена `aria-current="page"`.
- Усі зображення мають `alt`; фото подано у форматі WebP з JPG-запасним варіантом через `<picture>` і завантажуються ліниво (`loading="lazy"`).
- Форми: онлайн-запис, зворотний зв'язок, вхід і реєстрація; кожне поле має `<label>`.
- Усі сторінки перевірено W3C Validator (0 помилок).

## CSS (ЛР3)

- **Організація стилів:** `style.css` об'єднує `base.css`, `layout.css` і `components.css` директивою `@import`; кольори, шрифт і відступи винесено в CSS-змінні (`:root`).
- **Брендбук:** королівський синій `#395AB0`, темний синій `#364870`, пісочне золото `#E1CA8D`, статусні червоний `#C53030` і зелений `#1F7A4D`; шрифт Roboto (Google Fonts); прямокутні кнопки з тонкою рамкою.
- **Адаптивність (mobile-first):** медіазапити `@media (min-width: 600px)` для планшета та `@media (min-width: 900px)` для ПК; гнучкі розміри заголовків через `clamp()`.
- **Flexbox:** шапка, меню, кнопки, картки лікарів, рядки форм.
- **CSS Grid:** сітка популярних процедур (1 → 2 → 4 колонки), двоколонкові блоки «текст + фото», картки лікарів, підвал.
- **Бургер-меню без JavaScript:** прихований `checkbox` + `label`, меню відкривається селектором `.nav-toggle:checked ~ .main-nav`.
- **Валідація форм:** HTML5-атрибути `required`, `minlength`, `pattern`, `type="email"`; помилки підсвічуються через `:user-invalid` і `:has()` (лише після взаємодії з полем), під полем показується текст помилки.
- **Кросбраузерність** (Chrome, Firefox, Safari, Edge): префікси `-webkit-` для `backdrop-filter`, `appearance`, `text-size-adjust`; власна стрілка для `<select>`, однакова висота полів; фон головного екрана у форматі WebP.
- **Доступність:** посилання «Перейти до основного вмісту», видимий фокус `:focus-visible`, контраст тексту ≥ 4,5:1, повага до `prefers-reduced-motion`.
